# hybrid-agent-rail
Hybrid 跨端高性能Agent Harness 插件包，兼容 Codex， Claude Code，Cursor，Trae 等各种 Agent 平台。适配 React Native，Flutter，UniApp 等 跨端平台。
## 解决什么问题

- 跨端框架太多，作为初次开发者/其他领域的程序员不知道用哪一个问题。
- 不同框架的原生实现能否正常在跨端层工作，如何将原生的复杂概念，通过 同步异步 + 通信类型来完成功能。
> 这一块的主要原因是我发现: 在跨端的 App 业务开发中，最主要的问题是在通信过程中通信桥类型和同步异步导致的问题。
- 跨端的 UI 使用姿势，如何确保跨端 App 的 UI 能和设计图一致，而不是让 Agent 根据代码"纸上谈兵"
- 常见的第三方包推荐和使用姿势。避免 Agent 直接走从0到1的落地过程。
