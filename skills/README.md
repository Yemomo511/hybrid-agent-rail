## Hyar Skills
作为 Hyar 的原子能力散在当前仓库，负责为整个跨端工作提供基础能力和基础面控制。

## Upstream Skill
目前市面上有很多开发方法论相关的 Skill， 如`Superpower`指出需要提出计划，头脑风暴从而提出计划，`Grill` 指出需要不断的细节追问，刨根问底，防止没有考虑到的情况。Hyar 的工作流程将基于这些基础的流程 Skill 来加入对跨端本身的考虑。

## Hybrid Skill
跨端Skill 主要对跨端知识进行补充，你可以理解为跨端所有知识的大集合，此部分主要以收集开源的Skill为主，对未开源的Skill 进行补充部分。
