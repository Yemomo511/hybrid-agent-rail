## Hyar Adapter
Hyar 的 Agent 和 Framework 适配器，负责将本地的 Skill 和 Agent 资源适配到对应的 Agent 平台

## Rules
- 单个文件应该只包含一个 Class 类； 如果一个ts 文件属于单独的一个类模块，其命名应该使该类的名称。整个TS的命名采用驼峰式命名
- 当超过两行的代码重复使用多次，应当考虑将他提取为一个函数或者方法
- 多个平台适配或者多个框架存在相似步骤或者共同行为时，可以考虑使用策略模式，注意依赖倒置原则，确保可扩展性。
- 每个模块 持有一个 `index.ts`，负责统一对外暴露该模块的对外功能。需要保留其功能和对外接口。
> 设计模块时，请为自己假设如果我以后需要新增一个相似的策略模块，我是否能够从已有的接口进行实现即可完成接入，而不是大量复制相似的业务逻辑。
