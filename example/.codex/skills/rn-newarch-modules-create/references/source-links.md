## Reading Order

1. Read the current docs for the target RN version through the version selector.
2. Read release notes for the target version and the nearest previous stable release.
3. If the project must support Legacy Architecture, read the backwards compatibility guide.
4. If behavior differs from docs, search React Native issues and ReactWG discussions with the exact RN version, platform, and error text.
